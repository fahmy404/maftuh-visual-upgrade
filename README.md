# ملف مفتوح: MAFTUH — لعبة التحقيق الجنائي البوليسية في القاهرة

تطبيق أندرويد متكامل مبني بلغة Kotlin وإطار عمل Jetpack Compose، يروي مغامرة بوليسية شيقة تدور أحداثها في شوارع ومباني القاهرة (مدينة نصر). يتقمص اللاعب شخصية المحقق **النقيب يوسف المصري** لكشف ملابسات مقتل رجل الأعمال أحمد فتحي داخل شقته السكنية.

---

## 🌟 مميزات اللعبة وميكانيكيات التحقيق

1. **المسرح الميداني التفاعلي (2D Interactive Scenes):**
   - استكشاف مسرح الجريمة: **شقة ٤٢ - الدور الرابع بمدينة نصر**.
   - التجول في **شارع عباس العقاد** وفحص كشك البقالة، حوض الزرع، وكاميرات المراقبة، وسيارة المشتبه به.
   - زيارة **قسم شرطة مدينة نصر**، مكتب الطب الشرعي ومكتب القيادة.
   - تحكم سلس عبر شاشة اللمس ولوحة تحكم توجيهية (Virtual D-Pad) مع استشعار التصادم بالحوائط والأثاث.

2. **الكشاف الجنائي (Forensic Flashlight):**
   - تشغيل الكشاف المخروطي لإضاءة الزوايا المظلمة وكشف البصمات، الآثار المادية، وطبعات الأحذية الموحلة.

3. **جمع وفحص الأدلة الجنائية (Clues & Forensic Analysis):**
   - 10 أدلة جنائية متكاملة تشمل:
     - ساعة الحائط المتوقفة وفحص كسر تروسها عمداً.
     - كوب الشاي المخدر وبصمات الشريك شريف محمود.
     - وصلة الشاحن المنزوعة وهاتف الضحية المفقود.
     - مستندات الاختلاس المالي وشيكات الشركة.
     - شريط تسجيل كاميرا مراقبة سوبرماركت البركة.
     - تقرير الطبيبة الشرعية د. سلمى وتحديد التوقيت البيولوجي للوفاة.

4. **دفتر التحقيق الشامل (Detective Notebook):**
   - **الأدلة الجنائية:** قائمة الأحراز المجمعة، تصنيفاتها العلمية، وفحصها المجهري.
   - **المشتبه بهم والشهود:** سجل أقوال شريف محمود، دينا عادل، عمرو سعيد، وحسام فتحي مع مؤشرات حالة حجة الغياب (سليم / مشكوك فيه / منهار).
   - **الجدول الزمني:** تسلسل أحداث ليلة الحادثة بالساعة والدقيقة لكشف التناقضات.
   - **ملاحظات المحقق:** إمكانية تدوين ملاحظات تحقيق جديدة وحفظها تلقائياً.

5. **لوحة التحقيق الجنائي التفاعلية (Evidence Corkboard):**
   - لوحة الفلين الكلاسيكية بصور البولارويد للأدلة والمشتبه بهم.
   - إمكانية ربط الأدلة بالمتهمين بواسطة خيوط حمراء (Red Yarn Strings) لبناء شبكة الاستنتاج.

6. **غرفة الاستجواب والمواجهة بالدليل (Witness Interrogation):**
   - حوارات متفرعة وأسئلة تحقيقية واقعية.
   - خيارات **المواجهة بالدليل** لمباغتة المشتبه به بالأحراز المكتشفة وكسر حجة غيابه مع تنبيهات جنائية مثيرة.

7. **جلسة توجيه الاتهام وإصدار الحكم (Indictment & Verdict):**
   - تحديد المتهم، الدافع الجنائي، والأدلة الدامغة المؤيدة للإحالة.
   - تقييم درامي للحكم النهائي:
     - ★★★ **محقق ممتاز (امتياز):** إدانة قاطعة واعتراف كامل وإحالة للجنايات.
     - ★★ **محقق مبتدئ (جيد):** إحالة بكفالة لعدم كفاية الأدلة الدامغة.
     - ★ **إخفاق في التحقيق (ضعيف):** اتهام باطل وهروب الجاني الحقيقي.

---

## 🛠️ البنية التقنية

- **لغة البرمجة:** Kotlin (JDK 21)
- **واجهة المستخدم:** Jetpack Compose (Material 3 Dark Noir Theme)
- **معمارية الكود:** MVVM (Model-View-ViewModel) مع `StateFlow`
- **التخزين المحلي:** SharedPreferences لحفظ تقدم التحقيق والدرجات والنقاط تلقائياً
- **أيقونة التطبيق:** أيقونة مخصصة متكيفة (Adaptive Launcher Icon) تعكس طابع التحقيق وشعار الشرطة المصرية
