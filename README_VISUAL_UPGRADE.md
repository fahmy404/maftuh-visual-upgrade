# ملف مفتوح — MAFTUH (visual upgrade)

## What changed
- Replaced the old primitive apartment background with a detailed illustrated 2D environment.
- Rebuilt the police station and Cairo street backdrops in the same warm, cinematic art direction.
- Kept the character, clue-marker, interaction, evidence notebook, dialogue, and UI layers separate so the game remains interactive.
- Removed the extra blurry lighting overlay that was obscuring the scene.
- Fixed downward movement input.
- Repositioned the clue markers to align with the new apartment artwork.
- Updated collision rectangles to better align with the new room layout.

## Controls
- WASD / arrow keys: move
- Shift: run
- E / Enter: interact with nearby evidence or witness
- F: flashlight
- Tab / N: case notebook
- On mobile: use the on-screen virtual joystick and action controls.

## Project note
This project was supplied as a Google AI Studio playground source export and does not include a package.json. Import the source files into the existing Google AI Studio project to preview it with the original playground dependencies.
